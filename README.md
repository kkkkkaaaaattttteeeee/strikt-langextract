# Извлечение S-P-O триплетов через LangExtract

## Задача
Оценить пригодность библиотеки LangExtract + локальных LLM (Ollama)
для извлечения триплетов «субъект — предикат — объект» из русскоязычных новостей.

## Данные
- 49 текстов из `articles.csv` (Ведомости)
- Gold-разметка: 10 текстов через ChatGPT (`gold_chatgpt_clean.csv`, 192 триплета)

## Метод
- Промпт v3: синтаксический разбор по клаузам
- Модели: `qwen2.5:7b`, `qwen2.5:3b` (локально через Ollama)
- Метрики: strict (точное совпадение) + soft (Jaccard ≥ 0.5)
- Лемматизация: pymorphy3

## Результаты
| Модель | Soft P | Soft R | Soft F1 | Скорость |
|---|---|---|---|---|
| qwen2.5:7b | 0.475 | 0.466 | 0.459 | 92 сек |
| qwen2.5:3b | 0.363 | 0.269 | 0.289 | 38 сек |

**Итог:** 900 триплетов, 854 информативных, 696 уникальных субъектов.

## Файлы
- `langextract_triplets.ipynb` — полный пайплайн
- `articles.csv` — исходные тексты
- `triplets_stats_7b_processed.csv` — обработанные триплеты (7b)
- `triplets_stats_3b.csv` — для сравнения (3b)
- `gold_chatgpt_clean.csv` — эталон
- `top_subjects.png`, `top_predicates.png` — графики

## Выводы
- qwen2.5:7b лучше по всем метрикам, но в 2.4x медленнее
- Soft F1 = 0.46 — недостаточно для полной автоматизации,
  но подходит для полуавтоматической разметки
- Ограничения: местоимения не разворачиваются, pymorphy3 искажает имена собственные
